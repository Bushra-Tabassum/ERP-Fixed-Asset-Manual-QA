# Fixed Asset Management – Bug Reports

This section contains selected bug reports identified during manual QA testing of the Fixed Asset Management module.

The purpose of these reports is to demonstrate how defects were documented with clear reproduction steps, expected behavior, actual behavior, severity, priority, and supporting evidence.

## Bug Categories Covered

The sample reports include defects related to:

- Business rule violations
- Depreciation calculation issues
- Validation failures
- Role and permission issues
- Workflow and state transition problems
- Integration inconsistencies
- UI/UX issues
- Error handling

## Bug Report Structure

Each bug report includes:

- Bug ID
- Bug Title
- Module / Feature
- Steps to Reproduce
- Expected Result
- Actual Result
- Severity
- Priority
- Evidence / Screenshot

> All screenshots, data, identifiers, and system information have been sanitized or recreated for portfolio purposes.
