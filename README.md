# ERP Fixed Asset Management – Manual QA Portfolio

## Project Overview

This project showcases my hands-on Manual QA experience testing an ERP Fixed Asset Management module.

The module covers the complete asset lifecycle, including:

- Asset Creation
- Asset Finalization
- Capitalization
- Monthly Depreciation
- Asset Amendment
- Asset Disposal / Sale
- Accounting Transactions
- Role & Permission Control

My testing focused not only on individual screens, but also on complete business workflows, validations, calculations, permissions, and integration between related processes.

---

## Defect Investigation Approach

When an issue was found, I typically:

1. Reproduced the problem
2. Identified the affected workflow
3. Checked frontend behavior and validations
4. Reviewed API requests and responses where required
5. Compared actual behavior with expected business rules
6. Documented clear reproduction steps and supporting evidence
